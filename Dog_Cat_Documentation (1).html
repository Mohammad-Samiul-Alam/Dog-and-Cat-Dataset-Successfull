এই প্রজেক্টে YOLOv8 মডেল ব্যবহার করে ছবির ভেতরের বিড়াল (cat) ও কুকুর (dog) চিনে তাদের চারপাশে বর্ডার বক্স আঁকা হয়। একটি ছবিতে একাধিক প্রাণী বা দুটির মিশ্রণ থাকলেও কাজ করে। আপনাকে শুধু train/images ফোল্ডারে ছবি দিতে হবে—লেবেল, valid, test ও data.yaml নোটবুক নিজেই বানায়।

This project uses a YOLOv8 model to detect cats and dogs in images and draw a border box around each one. It works with several animals in one image, or a mix of both. You only put images in train/images; the notebook creates labels, valid, test and data.yaml itself.

৭. ভাইভা প্রশ্ন ও উত্তর7. Viva Questions & Answers

১. YOLO কী?1. What is YOLO?

YOLO (You Only Look Once) একটি রিয়েল-টাইম অবজেক্ট ডিটেকশন অ্যালগরিদম। এটি একবারেই পুরো ছবি দেখে বস্তুর অবস্থান (বক্স), ক্লাস ও কনফিডেন্স বের করে।

YOLO (You Only Look Once) is a real-time object detection algorithm. It looks at the whole image in one pass and outputs boxes, classes and confidence scores.

২. Classification ও Detection-এর পার্থক্য কী?2. Classification vs Detection?

Classification পুরো ছবির একটি লেবেল দেয় (যেমন "কুকুর")। Detection বস্তুটি কোথায় আছে তা বক্স দিয়ে দেখায় এবং একাধিক বস্তু শনাক্ত করতে পারে।

Classification gives one label for the whole image (e.g. "dog"). Detection also tells where each object is with a box and can find several objects.

৩. লেবেল ফাইলে কী থাকে?3. What does a label file contain?

প্রতি লাইনে: class x_center y_center width height। মানগুলো ০ থেকে ১-এর মধ্যে normalize করা। 0 = cat, 1 = dog।

Each line: class x_center y_center width height, normalized between 0 and 1. 0 = cat, 1 = dog.

৪. লেবেল কীভাবে অটো তৈরি হয়?4. How are labels created automatically?

COCO-তে প্রশিক্ষিত YOLOv8m মডেল প্রতিটি cat (15) ও dog (16) খুঁজে বক্স বের করে এবং তা YOLO ফরম্যাটে সেভ হয়। এটি pseudo-labeling; তাই কিছু বক্স অসম্পূর্ণ হতে পারে।

A COCO-pretrained YOLOv8m finds each cat (15) and dog (16) and the boxes are saved in YOLO format. This is pseudo-labeling, so some boxes may be imperfect.

৫. Train, Valid ও Test কেন আলাদা?5. Why separate Train, Valid and Test?

মডেল training ছবি মুখস্থ করে ফেলতে পারে (overfitting)। Valid দিয়ে ট্রেনিংয়ের সময় এবং Test দিয়ে নতুন ছবিতে সঠিক মূল্যায়ন করা হয়।

A model can memorize training images (overfitting). Valid checks progress during training; Test gives an honest score on unseen images.

৬. Epoch, batch size ও imgsz কী?6. What are epoch, batch size and imgsz?

Epoch = পুরো ডেটা একবার দেখা (এখানে ২০ বার)। Batch = একসঙ্গে কতগুলো ছবি প্রসেস হয় (৮)। imgsz = ছবির আকার (৬৪০ পিক্সেল)।

Epoch = one full pass over the data (20 here). Batch = images processed together (8). imgsz = input image size (640 px).

৭. Confidence ও IoU কী?7. What are confidence and IoU?

Confidence = মডেল কতটা নিশ্চিত (এখানে ≥ 0.25)। IoU = দুটি বক্সের ওভারল্যাপের অনুপাত; NMS-এ ডুপ্লিকেট বক্স বাদ দিতে ব্যবহৃত হয়।

Confidence = how sure the model is (≥ 0.25 here). IoU = overlap ratio of two boxes; used in NMS to remove duplicate boxes.

৮. mAP, Precision ও Recall কী?8. What are mAP, Precision and Recall?

Precision = ডিটেক্ট করাগুলোর মধ্যে কতটি সঠিক। Recall = আসল বস্তুর মধ্যে কতটি পাওয়া গেছে। mAP = সামগ্রিক ডিটেকশন মান।

Precision = how many detections are correct. Recall = how many real objects were found. mAP = overall detection quality.

৯. best.pt ও last.pt-এর পার্থক্য?9. best.pt vs last.pt?

best.pt হলো valid ফলাফল সবচেয়ে ভালো হওয়া epoch-এর ওয়েট; last.pt হলো শেষ epoch-এর।

best.pt holds the weights from the epoch with the best validation result; last.pt is from the final epoch.

১০. একাধিক প্রাণী বা মিশ্র ছবি কীভাবে সামলানো হয়?10. How are multiple or mixed animals handled?

প্রতিটি প্রাণীর জন্য আলাদা বক্স ও ক্লাস লেবেল হয়। একটি ছবিতে একাধিক লাইন থাকে (cat ও dog দুটোই থাকতে পারে)। ফাইলের নাম দিয়ে শুধু একক-প্রাণীর ছবির ক্লাস ঠিক করা হয়।

Each animal gets its own box and class, so one image can have many lines (cats and dogs together). The file name is used only to correct single-animal images.

১১. এই পদ্ধতির সীমাবদ্ধতা কী?11. What are the limitations?

লেবেল মেশিন-তৈরি বলে ভুল থাকতে পারে; ঘন ভিড় বা আংশিক ঢাকা প্রাণী মিস হতে পারে; ছোট ডেটাসেটে নির্ভুলতা কম হয়। হাতে-করা লেবেল (যেমন Roboflow) আরও ভালো।

Labels are machine-made so may contain errors; crowded or partly hidden animals can be missed; small datasets give lower accuracy. Hand-made labels (e.g. Roboflow) are better.
